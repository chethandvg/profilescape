Your GitHub profile, rendered as a landscape

Profilescape turns your contributions, languages and projects into a matching set of animated SVG cards for your profile README. It runs as a GitHub Action in your own repository with your own token: no rate limits, no servers, private contributions optional.

Your setup

Save as .github/workflows/profilescape.yml in your profile repository (the one named after your username). Only settings that differ from the defaults are included.

Quick start

Live on your profile in three steps

About five minutes, no servers and no secrets required.

  1. 1

    Create your profile repository

    GitHub shows the README of the public repository named exactly like your username, for example octocat/octocat. Or start from the template, which already has the workflow and markers.

    Use the template

  2. 2

    Add the workflow

    Copy the workflow from the playground into .github/workflows/profilescape.yml, or start from this minimal one:

    name: Profilescape
on:
  schedule:
    - cron: "23 4 * * *" # every day
  workflow_dispatch:
permissions:
  contents: write
jobs:
  cards:
    runs-on: ubuntu-latest
    steps:
      - uses: chethandvg/profilescape@v1
        with:
          readme: README.md
  3. 3

    Add the markers and run it

    Put <!-- profilescape:start --> and <!-- profilescape:end --> in your README, then open Actions → Profilescape → Run workflow. Your cards appear in about a minute and refresh every day.

Private contributions

The default workflow token sees public activity. Add a fine-grained personal access token (All repositories; read-only Contents and Metadata) as the PROFILESCAPE_TOKEN secret to include private repositories and contributions. It is only ever used to read.

Prefer the terminal?

The CLI renders the same cards into a profilescape folder. Try it without a token:

npx github:chethandvg/profilescape --demo --cards all
